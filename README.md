# Tuana

Palästinensisch-jordanisches Arabisch aus dem Alltag lernen: sprechen, lesen, schreiben.

- **Sprechen:** echte Situationen (Falafel-Stand, Sammeltaxi, Teta, WhatsApp, Souq)
- **Lesen:** Alphabet nach Formfamilien, Schilder und Speisekarten lesen
- **Schreiben:** Buchstaben nachzeichnen, Wörter zusammensetzen
- **Wörter:** Karteikarten mit Ausdrücken, die man wirklich hört
- Umschalter Palästina / Jordanien

## Aufs Handy

Seite im Browser öffnen, dann:
- **iPhone (Safari):** Teilen › „Zum Home-Bildschirm“
- **Android (Chrome):** Menü ⋮ › „App installieren“ / „Zum Startbildschirm hinzufügen“

Funktioniert danach auch offline. Der Lernfortschritt wird auf dem Gerät gespeichert.

## Bearbeiten

Inhalt steht in `src/app.html`. Danach `./build.sh` ausführen, damit `index.html` neu gebaut wird,
und in `sw.js` die `VERSION` erhöhen.
